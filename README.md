# Whatever

A Chrome extension for building digital outfit collages right inside your browser side panel.

## What it does

- Drag clothing images from online shopping sites straight onto your workspace.
- Automatically clears out background whites without chewing into light-colored clothes.
- Keeps track of your dropped items in an inventory rack at the bottom.
- Resize, rotate, and layer garments freely.
- Switch between different paper and journal background textures.
- Export your finished outfit as a Polaroid-style image download.

## How to install it

1. Download or clone this project folder to your computer.
2. Open Google Chrome and type `chrome://extensions` in the address bar.
3. Turn on **Developer mode** using the toggle switch in the top right corner.
4. Click the **Load unpacked** button in the top left.
5. Select your project folder.

## How to use it

- Open the extension side panel in your browser.
- Drag any clothing image from a web page onto the board.
- Use the corner handle on items to resize them, or the rotation buttons to tilt them.
- Use the toolbar controls on each card to change layers or remove items.
- Click items in your bottom rack to add them back to the board whenever you want.
- Click the save button to download your final outfit as an image file.
